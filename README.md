## What in the Name of Liberty is This?!
This is one of my first personal projects that came to mind because I love a video game called Helldivers 2.
In the game you have stratagems that you take onto missions and usually you pick the same ones you like over and over again as your "load-out"
This flips that upside down by granting you a completely random load-out of 4 stratagems every single time you run it, based off the Warbonds you have unlocked.
By default, the base ship  stratagems that are unlocked with requisition slips are included in the list so even if you don't have a single Warbond, you can still do this challenge. 
As of right now, in order to use the code since it is written in python you would have to have python installed on your machine so your computer can interpret the code.
In the future or if anyone has any recommendations, I will either change the language to something like Go, or will find a way to compile into an executable that will download python alongside the code.
